حسابیار — نسخه انتشار ۲

ویژگی‌ها:
- PWA قابل نصب و اجرای آفلاین
- ثبت درآمد و هزینه
- رمز ورود محلی با PBKDF2/SHA-256
- قفل برنامه و تغییر رمز
- پشتیبان‌گیری و بازیابی تراکنش‌ها
- اطلاعات تراکنش‌ها روی همین دستگاه ذخیره می‌شود

نکته امنیتی:
این رمز برای جلوگیری از ورود معمولی به برنامه روی همان دستگاه است، نه احراز هویت سروری. اگر رمز فراموش شود، در این نسخه بازیابی رمز وجود ندارد و پاک‌کردن داده‌های سایت/برنامه باعث حذف تراکنش‌ها می‌شود؛ قبل از هر تغییر مهم از پشتیبان JSON استفاده کنید.

استقرار:
همه فایل‌های این پوشه را در ریشه GitHub Pages/Cloudflare Pages قرار دهید.
